🛡️ Guardian Fault Handling & Observability

Enterprise Reliability & Automated Error Diagnosis

Preview Diagnostic 404 Screen →

🔍 404 Guardian

Detects URL typos with fuzzy matching, suggests valid routes, prevents open-redirect exploits, and smoothly routes browser traffic to /404?from=....

🚨 5xx Server Guardian

Intercepts unhandled server exceptions, classifies database, schema, query, or view faults, tags incidents with ERR-* IDs, and protects stack traces in production.

📊 Dual-Sink Telemetry

High-resolution request logger captures duration, MIME type, response size, and IP to both terminal console and persistent logs/error.logs.

🗄️ Dual Persistence

PostgreSQL 16 connection pooling via models/db.js with Docker Volume persistence and seamless in-memory fallback for offline test suites.
