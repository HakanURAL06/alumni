About This Project

🎓 Alumni Tracking System

A simple alumni tracking application designed to organize, search, and manage alumni profiles and records.

🎯 Purpose & Core Capabilities

The primary goal of this application is to establish a centralized portal for managing alumni data and maintaining institutional connections. It facilitates:

  • Profile Management: Storing graduation year, academic department, contact details, and career/employment history.
  • Search & Filter: Quickly discovering alumni by graduation year, field of study, or current professional status.
  • Continuous Engagement: Providing structured records to foster alumni networks and mentorship opportunities.

💻 Tech Stack & Architecture

  • Frontend (JavaScript): Powers responsive UI rendering, dynamic DOM manipulation, and asynchronous API communication (fetch / axios) for instantaneous profile filtering without page reloads.
  • Backend (Node.js & Express): Serves RESTful API endpoints, request validation, authentication, and communication with the database.
  • Database (PostgreSQL): Relational database providing strict schema integrity, indexing, foreign key constraints, and transactional consistency for all alumni records.
  • Containerization (Docker & Docker Compose): Fully containerized runtime ensuring reproducible zero-configuration execution across any environment with a single command.
